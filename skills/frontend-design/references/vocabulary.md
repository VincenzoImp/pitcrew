# Design vocabulary

Short words the owner uses about a design, and the operations they mean here. When the owner uses
a word in a different way, or a new word, ask once what they mean, apply it, and propose a line
for this table.

| Word | Operations |
| --- | --- |
| bolder | larger steps in the type scale and in weight; one dominant element per screen; fewer competing accents. Not gradients or neon. |
| quieter | fewer colours and borders; lower contrast on secondary items; more white space. |
| denser | less padding; smaller secondary text; more rows per screen; touch targets stay usable. |
| airier | more space between groups than inside them; shorter lines (45 to 75 characters). |
| distill | remove elements until the main task is still clear; merge duplicate actions. |
| clearer | stronger hierarchy: one idea per heading level, labels next to values, the main action first. |
| polish | align to the grid; consistent radii, shadows and icon sizes; check every state. |
| harden | make it work for every state, width, slow network, long text, keyboard and screen reader. |
| warmer | softer neutrals with a warm tint, rounder type, friendlier copy; keep contrast. |
| sharper | smaller radii, tighter spacing, stronger contrast lines, a more geometric type face. |
